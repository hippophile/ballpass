# Media assets (demo)

All files are self-hosted under `src/Ballpass.Web/wwwroot/media/` (no hotlinking). Total budget 40 MB. Stock photos are labelled in the UI "Εικόνα αρχείου · demo" / "Stock image · demo" and never claim to show the named athlete; videos are generated graphics labelled "Γραφικό · demo".

## Sourcing

- Photos: Wikimedia Commons files whose file page states **CC0** (most are Unsplash uploads from before the Unsplash licence change, tagged CC0 on Commons). Commons API queried with an honest client User-Agent; Pexels/Unsplash site pages were not scraped.
- Excluded after visual inspection: photos with recognisable faces, children, or a named real player's jersey.
- Brand marks (Nike, Spalding, Wilson, Molten) appear incidentally on balls/shoes; no endorsement is implied.
- Videos: generated by `ffmpeg` + Pillow as schematic motion graphics (code: not shipped; reproducible from the description in each row). No real footage was used, because every freely licensed basketball video found shows identifiable people.
- Processing: photos `cwebp -q 72`, max side 1280 px; videos H.264 CRF 27, 960x540, 8 s, 24 fps, no audio; posters WebP q78.
