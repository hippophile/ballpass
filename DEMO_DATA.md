# Demo data

All athletes, coaches and clubs in the demo database are **fictional**. They are generated by
`src/Ballpass.Web/Demo/DemoDataGenerator.cs` from a fixed seed (42), so every reset gives the identical data set.

| What | Count |
|---|---|
| Athletes | 200 women + 100 men |
| Clubs | 20 (12 women, 8 men) |
| Coaches | 30 (20 head, 10 assistant) |
| Seasons / stat lines | 1-3 per athlete (2023-24 to 2025-26) |

## Rules
- **`IsDemo` flag**: every club, coach and athlete row has `IsDemo = true`. Reset deletes only flagged rows.
- **"(demo)" clubs**: every club name ends with ` (demo)` and uses an invented nickname, not a real club name.
- **No minors**: all athletes are 18-34 years old on 2026-01-01 (birth years 1992-2008).
- **No videos**: `VideoUrl` is always empty.
- **Bios** are generic Greek text; they mention no real clubs or people.

## Stat source labels
Each stat line carries a `Source` (trust label): `SelfReported` (about 60%), `CoachConfirmed` (about 25%),
`LeagueVerifiedMock` (about 15%).
**`LeagueVerifiedMock` is a mock.** There is no league or partner behind it; it only shows what a verified
label would look like. Stats are plausible, not real distributions.

## Reset
```
make reset
```
Applies migrations, deletes all demo rows and inserts the generated set in one transaction. Safe to run repeatedly.
`make setup` runs it at the end. Normal app startup does not migrate or seed.

## Caveat
Names are random combinations of common Greek first names and surnames. A combination can match a real person
by chance. That is why every page shows the demo banner, every row is flagged `IsDemo`, and clubs carry "(demo)".
